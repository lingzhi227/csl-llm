# Regional runtime contracts

The pinned SDK collectives implementation derives dimensions and coordinates from the complete application rectangle. The successful eight-PE origin test does not qualify arbitrary subregions. The new static line protocol takes an explicit region-relative ordinal, participant count and physical directions to adjacent participants. It retains the same colors and queues throughout its lifetime.

The bounded two-region test used real128×896 UP contractions from layers0/12, at origins(2,1)/(12,1), eight PEs each. Three colors implement alternating nearest-neighbor reduction and a separate multicast return; queue2 is reduction and queue3 is broadcast. DSR bank1 belongs to asynchronous communication; the synchronous matrix kernel uses3/4 before communication. Two launches each execute four device-side epochs, with reset and changed input between launches. All observed per-PE histories and six guard locations passed. Evidence is `evidence/regional-linear-20260908T072157772253Z`. Compilation's greedy allocator had intermediate failures; final DSATUR graphs for all19 classes were valid. Do not treat an intermediate allocator attempt as a final compiler failure.

A callback proves completion of its local descriptor operation. It does not prove that every network queue is empty. This protocol neither changes routes nor releases shared queues between epochs. Fixed message extents and identical operation order on every participant preserve FIFO correspondence, while a PE keeps its source/destination storage until its local completion. The host command stream remains blocked until the local sequence finishes. Reconfiguration, module substitution, concurrent protocols on these queues or global release require additional evidence.

The unpublished attention development variant adds sum/max and a per-operation extent bounded by the instance's capacity. Every participant must issue the same operation kind and count in the same order. Empty KV stripes contribute a negative finite maximum sentinel and zero denominator/context. The seven Q heads sharing a KV head retain separate statistics. Separate bounded real-trace and diagnostic-capacity runs now qualify their selected frozen variants; see docs/MILESTONES.md. The earlier sum-only evidence alone does not qualify these extensions.

For future cross-region packets, SDK message_passing is a candidate. Its routing bank number14 is distinct from DSR bank IDs and local task IDs. The fixed-length public header encodes at most31 wavelets. A packet format must account for metadata within that length, own transmit storage until completion, and preserve receive queue ownership. The public recv_message reads its header synchronously, so an event-driven adapter requires an actual SDK test rather than assuming idle reception is nonblocking. No private SDK state mutation or vendored modification is part of this design.
