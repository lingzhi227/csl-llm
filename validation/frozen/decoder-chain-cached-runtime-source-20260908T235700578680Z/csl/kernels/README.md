# Local CSL kernels

`local_gemv_f32.csl` adapts the f32 memory-DSD column accumulation pattern from Cerebras SDK `tutorials/gemv-02-memory-dsds/pe_program.csl`, Copyright 2025 Cerebras Systems, Apache-2.0 (included LICENSE). The unchanged source reference is in the preserved sibling `csl-hls/ports/projects/sdk_examples/upstream/`. Changes introduce a reusable pointer API, explicit per-call descriptor construction/reset and destination clearing. The module uses synchronous operations and no fabric colors or application tasks; enclosing SDK memcpy infrastructure still owns its resources.

Inputs: row-major weights `[rows, columns]`, input `[columns]`, output `[rows]`, all f32. Output must not alias either input. Static local dimensions must fit SRAM/DSD stride limits; source parameter acceptance is not an arbitrary-shape qualification. Initial measured scope is rows32/columns224, one real Qwen layer0 UP slice, three repeated calls. Replicated-grid probes characterize simulation cost and do not qualify a distributed model contraction.


`local_gemv_bf16_f32_colmajor.csl` stores original BF16 words in `[columns, rows]` order, expands one column exactly into FP32 scratch and accumulates with FP32 FMA. It exclusively leases destination/source DSR banks3/4 synchronously; generated allocator graphs also contain automatically allocated descriptors for initialization and map input. Callers must join earlier asynchronous users before entry. Inputs and output must be disjoint. Every call clears output/scratch and reloads persistent descriptors. The128×112 local kernel and eight-shard128×896 contraction have actual SDK evidence; that does not qualify arbitrary shapes or concurrent DSR reuse.

`vector_f32.csl` uses the SDK BLAS reduction-map structure (Apache-2.0, from the preserved SDK benchmark reference) and SDK math. It adds synchronous RMSNorm, stable-sign SwiGLU, dense finite softmax and residual operations. RMS epsilon is the pinned Qwen1e-6 value; finite inputs and representable squared sums are required. Length is bounded to2048 at compilation. Function-specific alias requirements are documented in source. These new operators are awaiting SDK qualification; parameter bounds alone are not supported-shape evidence.
